# Pulsar-p-pdot-graph
Hello,
This is my repository to track my progress in creating a p/pdot diagram for the pulsars located within the Globular cluster NGC104.
NGC104 is a GC that I looked into for my microproject postgard masters research group. During the microproject the group looked at evolutionary tracks of stars within globular and open clusters. When writing up my lit review, I found out NGC104 has 
pulsars. Pulsars have been an interest of mine since 2022/2023. Due to both of these factors I am attempting to create a p/pdot diagram for the pulsars located within the GC. I have not yet written code for something like this before. So there will be updates.
As of right now the code is just skeleton code, of how I think it could work. No plots are produced yet of 26/08/2026. I also have to go over the pulsar physics and maths as I think I may have a slight misunderstanding of how they work.
Either way I hope this inspires some other pulsar enthusiasts out there.
